# Security policy

Lumigram is a front-end prototype with no backend, authentication or stored data. Report
suspected vulnerabilities privately via GitHub's "Report a vulnerability" form on this repository
or by email to praneetha1844@gmail.com. This is a personal project with no response-time guarantee.

The code has no secrets and makes no network requests other than loading its own static files.
Dependencies are not yet scanned automatically; see [docs/ROADMAP.md](docs/ROADMAP.md).
